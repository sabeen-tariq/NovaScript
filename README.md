# NovaScript 🚀

NovaScript is a simple programming language interpreter built using C++.

## Features
- Variable declaration using LET
- Basic arithmetic operations
- Print statements
- Command-line interface

## Example Code

LET x = 10
LET y = 20
PRINT x + y
PRINT x
